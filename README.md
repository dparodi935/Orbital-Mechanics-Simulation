# Astrodynamics
Astrodynamics library containing various tools. Accessed with a CLI

## Features: 
- Gravitational Simulator
    - Runge-Kutta-Fehlberg Integrator
    - Execute maneuvers
    - Create both 2D and 3D animations
- Calculates Lagrange points 
- Lambert's Solver
- Porkchop Plot
